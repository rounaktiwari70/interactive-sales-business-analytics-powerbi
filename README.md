# 📊 Interactive Sales & Business Analytics Dashboard

An interactive **Sales & Business Analytics Dashboard** built using **Microsoft Power BI** to analyze sales performance, profitability, customer segments, regional trends, and product-level performance.

The dashboard transforms the Superstore sample dataset into an interactive business intelligence report with KPIs, dynamic filters, and visual analytics.

---

## 🎯 Project Objective

The objective of this project is to analyze sales and profitability data and create an interactive dashboard that helps users:

- Monitor overall business performance
- Analyze sales and profit trends
- Compare regional performance
- Identify high-performing categories and products
- Understand customer segment contribution
- Track key business KPIs
- Explore data using interactive filters

## 📈 Dashboard Features

### KPI Metrics

The dashboard includes the following key performance indicators:

- **Total Sales:** 2.33M
- **Total Profit:** 292.30K
- **Total Orders:** 5K
- **Total Customers:** 804
- **Total Quantity:** 39K
- **Profit Margin:** 12.6%

### Interactive Visualizations

- 📈 Monthly Sales Trend
- 🍩 Sales by Category
- 📊 Sales by Segment
- 🏆 Top 10 Products by Sales
- 🌎 Sales by Region
- 💰 Profit by Category

### Interactive Filters

Users can dynamically analyze the dashboard using:

- Year
- Region
- Category
- Segment

---

## 💡 Key Insights

- Technology generates the highest sales among the analyzed categories.
- The West region records the highest sales.
- The Consumer segment contributes the largest share of sales.
- Canon imageCLASS 2200 is the top-selling product.
- Overall profit margin is 12.6%.

---

## 📌 Recommendations

- Focus on high-performing Technology products.
- Strengthen sales activities in lower-performing regions.
- Develop targeted offers for the Home Office segment.
- Review low-profit categories to improve margins.
- Explore cross-selling opportunities among customers.

## ⚙️ How to Use

1. Download the repository.
2. Open `Superstore_Sales_Analytics.pbix` using **Power BI Desktop**.
3. Ensure the dataset path is available if Power BI requests it.
4. Refresh the data if required.
5. Use the dashboard slicers to explore different business dimensions.
